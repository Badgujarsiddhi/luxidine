# LuxeDine Chatbot - Getting Started

This project is a premium restaurant ordering chatbot built with HTML, CSS, and JavaScript.

## How to Run in VS Code

Follow these steps to get the project running locally:

### 1. Open the Project
- Launch **Visual Studio Code**.
- Go to `File` > `Open Folder...`
- Navigate to and select the folder: `c:\Users\siddh\OneDrive\Desktop\Documents\Kalyanicss`.

### 2. Install Live Server (Recommended)
To see your changes in real-time and ensure everything loads correctly, it's best to use the **Live Server** extension:
- Click on the **Extensions** icon in the Activity Bar on the side of VS Code (or press `Ctrl+Shift+X`).
- Search for "Live Server" by Ritwick Dey.
- Click **Install**.

### 3. Launch the Chatbot
- Open the `index.html` file from the Explorer side bar.
- Right-click anywhere in the code editor and select **Open with Live Server**.
- Alternatively, click the **Go Live** button at the bottom-right corner of the VS Code window.
- Your default browser will open automatically with the chatbot running.

## How to Run from Terminal

If you prefer using the terminal, you can use one of these methods:

### Method A: Using Node.js (npx)
If you have Node.js installed, run:
```bash
npx http-server
```
Then open `http://localhost:8080` in your browser.

### Method B: Using Python
If you have Python installed, run:
```bash
python -m http.server
```
Then open `http://localhost:8000` in your browser.

### Method C: Direct Open (Windows)
To simply open the file in your default browser:
```powershell
start index.html
```

### 4. Interact with the Bot
- Type "Hi" or "Hello" to start.
- Type "Show menu" to see the dishes.
- Type "I want something spicy" for recommendations.
- Type "Order [Item Name]" to place an order.

## Folder Structure
- `index.html`: The main user interface.
- `style.css`: The premium glassmorphism styling.
- `script.js`: The chatbot logic and menu data.
